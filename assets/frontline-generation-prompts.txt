3. fonts/frontline-black.woff2
此文件不是 imagegen 产物。
源字体：本地已安装的完整 Noto Sans SC 可变字体 NotoSansSC-VF.ttf；本轮未下载源字体。
许可：SIL Open Font License 1.1，许可原文随字体保存在 fonts/OFL.txt。
许可来源：https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/OFL.txt
工具：fontTools 4.60.2、Brotli 1.2.0。
方法：固定 wght=900，更新静态字体名称，再编码为 WOFF2；不调用字符子集工具，不移除源字体字符。
实际转换所用核心代码（路径替换为相对示例）：

from fontTools.ttLib import TTFont
from fontTools.varLib.instancer import instantiateVariableFont

font = TTFont("NotoSansSC-VF.ttf")
original_cmap = font.getBestCmap()
original_glyphs = font.getGlyphOrder()
instantiateVariableFont(font, {"wght": 900}, inplace=True, optimize=True, updateFontNames=True)
font.flavor = "woff2"
font.save("assets/fonts/frontline-black.woff2")
font.close()

with TTFont("assets/fonts/frontline-black.woff2") as result:
    assert result.getBestCmap() == original_cmap
    assert result.getGlyphOrder() == original_glyphs
    assert "fvar" not in result
    assert result["OS/2"].usWeightClass == 900

生成时核对结果：31,036 个字形、30,890 个 Unicode 码位，字符映射和字形顺序与源字体一致；无 fvar 可变轴，OS/2.usWeightClass 为 900，family 为 Noto Sans SC Black；WOFF2 文件 3,999,888 字节。
